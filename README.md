# Nút Âm Lượng (Floating Volume Button)

## Build APK
**Cách 1 - Android Studio:** File > Open thư mục này > Build > Build APK(s).
APK nằm ở app/build/outputs/apk/.

**Cách 2 - GitHub (không cần cài gì):** Tạo repo, upload toàn bộ thư mục,
vào tab Actions > Build APK > tải file ở mục Artifacts.

## Sử dụng
Mở app > "Bật nút nổi" > cấp quyền "Hiển thị trên ứng dụng khác" > bấm lại "Bật nút nổi".
Chạm nút nổi để hiện thanh âm lượng, kéo để di chuyển.
